# robot-project
Проект для курса "Объектно-ориентированное программирование".

Посвящён созданию виртуального экспериментального стенда
для работы с тензочувствительными датчиками.

Ближайшая "контрольная точка": создание разомкнутого контура управления
для проверки гипотезы об эффективности восстановления контактного усилия
с помощью динамической калибровки (по материалам моей статьи).
